# FLASHPACKER
We're building a platform that simplifies short-term stays by connecting travelers with unique, verified accommodations offered by local hosts. Our goal is to create a trusted space where users can discover, book, and manage stays that fit their lifestyle — whether it's a weekend getaway, a remote work retreat, or a city adventure. By focusing on user experience, transparency, and community, we're aiming to reimagine the way people find places to stay, while also empowering hosts to monetize their spaces effortlessly.
# Technology used
1. MongoDB - Define and manage API routes for user authentication, trip creation, expense tracking, and other services.
2. ExpressJS - Express.js is a minimal web framework for Node.js that helps us build RESTful APIs quickly. It is crucial for handling HTTP requests, routing, and middleware. It defines and manages API routes for user authentication, trip creation, expense tracking, and other services.
3. EJS Templates - EJS is a templating engine that allows us to generate HTML markup with plain JavaScript. It is used to render dynamic content on the frontend by embedding JavaScript code directly into HTML templatesEJS helps:
    Dynamic Content Rendering: Dynamically generate HTML pages based on user inputs, trip details, weather data, and more.
   Templating Flexibility: Create reusable templates (e.g., for trip listings, itineraries, accommodation details) that are populated with real-time data from the backend.

Seamless Integration: Provide a straightforward way to integrate the frontend with backend data without needing to manage complex client-side JavaScript frameworks like React. The templates are rendered server-side, ensuring fast initial load times and easier SEO management.
4. NodeJS - Node.js is a JavaScript runtime that allows us to run JavaScript code on the server side. Enables the development of a full-stack JavaScript application (both frontend and backend).Offers high performance due to its non-blocking, event-driven architecture, which is perfect for handling multiple requests, such as fetching travel data or handling user authentication.
